# IGリール量産キット 仕様書(Codex/他エージェント引き継ぎ用)

このドキュメント単体で、初見のAIエージェント(Codex等)が同じ品質のIGリールを作れるように書いてある。
対象: 髙橋航大(Kodai)のIGリール。US市場向け、横撮り16:9素材→縦1080x1920変換、英語キャプション焼き込み。

## 0. 環境セットアップ(Linux想定)

```bash
apt-get update && apt-get install -y ffmpeg fonts-noto-cjk
pip install pillow faster-whisper
```

- フォント: Noto Sans CJK JP(`/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc` / `-Regular.ttc`)
- Mac の場合はヒラギノ角ゴ W7/W6 に置き換え可(`build_reel.py` 冒頭の FONT_B/FONT_R を変更)

## 1. ファイル構成

```
tools/reel/
  build_reel.py                  # ビルドエンジン(spec JSON → 完成mp4)
  example_spec_tomioka_A.json    # 完成形のspec例(これを雛形にする)
  CODEX_SPEC.md                  # 本書
```

作業ディレクトリに `src/` を作り、元素材(mp4)を置く。実行:

```bash
python3 build_reel.py spec.json   # → out/<name>.mp4
```

## 2. spec JSON スキーマ

```jsonc
{
  "name": "出力ファイル名",          // out/<name>.mp4
  "fps": 30,
  "audio": "keep",                  // 元音声を維持
  "fade_out": 0.7,                  // 末尾フェード秒(映像+音声)
  "music_bed": {                    // BGMベッド(全編)
    "src": "src/xxx.mp4",           // 音楽の取り出し元
    "intro_in": 10.5,               // 曲の盛り上がり部分の開始秒(冒頭に使う)
    "intro_len": 3.4,
    "in": 0.5, "len": 10.0,         // ループさせる楽曲のみ区間(VOが乗っていない区間限定!)
    "v_hi": 0.95,                   // 冒頭(フラッシュ中)の音量
    "v_lo": 0.14,                   // 喋り出し以降の音量(ダッキング)
    "duck_at": 2.9, "duck_len": 1.0 // ダッキング開始秒と遷移秒
  },
  "segments": [                     // 出力順に連結される
    {"src":"src/a.mp4","in":12.4,"out":13.15,"crop_x":960,"mute":true},
    // crop_x: 1920px中の被写体の顔の中心X。608x1080をこの中心で切り出し→1080x1920へ拡大
    // crop:[w,h,x,y]: 明示ズームクロップ(縦横比 9:16 を守ること)
    // vsrc+vin: 映像を別ソースから取る(音声は src/in のまま)→ ナレーション+B-roll構成用
    // mute: true で無音化(冒頭フラッシュに必須)
    // speed: 再生速度(省略時1.0)
  ],
  "hook": {                         // 冒頭の上部フックテキスト
    "en":"...", "ja":"...", "dur":5.5,
    "loc":"Tomioka Silk Mill · 富岡製糸場"   // 場所表記(必須)
  },
  "top_labels": [                   // 上部黒バンド+ラベル(任意)
    {"s":19.4,"e":32.0,"en":"...","ja":"..."}
  ],
  "cues": [                         // 焼き込み字幕(出力タイムライン基準の秒)
    {"s":0.4,"e":5.8,"en":"英語(主役・64px太字白)","ja":"日本語(上段・40px黄)"}
  ]
}
```

## 3. 制作フロー(必ずこの順)

1. **素材確認**: `ffprobe` で解像度/尺/回転を確認。`fps=1/N,tile` でコンタクトシートを作り目視
2. **文字起こし**: faster-whisper(発見=small、確定箇所の精査=large-v3)。16kHz mono wavを渡す
3. **候補提示**: いきなり作らない。カット候補・構成・キャプション案を表で提示(3〜5案+推奨1つ)。ただし「作ってみて」と言われたら即v1
4. **クロップ検証(必須)**: 採用カットの複数フレームに実際のクロップ窓を当てたテスト画像を作って目視確認してからspecに書く。被写体が動くカットは分割して追従
5. **ビルド** → **セルフチェック**: 完成品から8〜10フレーム抽出して目視(顔見切れ/字幕衝突/謎カットを自分で見つけて直す)
6. **納品**: 投稿セット単位(動画+カバー2案+IGキャプション+固定コメント+チェックリスト)

## 4. 絶対ルール(過去の実フィードバックから)

- **顔見切れは絶対NG**。クロップは推測せず必ず実フレームで検証
- **冒頭の完全無音NG/BGMぶつ切りNG** → music_bedで曲を全編に通す(冒頭は曲の盛り上がり、喋りからダッキング)
- **冒頭はインパクト**: 0.75秒×4フラッシュフォワード(mute)+フックテキスト+場所表記
- **意味が一目で分からないB-rollは使わない**(暗い・被覆機材など)
- **元動画の焼き込みテロップ対策**: 対談カットは映像をB-rollに差し替えて声だけ使う(vsrc/vin)。クロップで切れた中途半端なテロップを残さない
- **カット尻は発言の語尾ぴったり**(例:「やっていきたいですね。」で終える)+fade_out 0.7
- 台詞の途中で切らない。whisperタイムスタンプ±0.3〜1.0秒パディング
- 尺: トーク系45〜55秒目標(30〜65許容)
- 字幕: EN 64px太字白(主役)/JA 40px黄(上段控えめ)。全テキスト自動縮小で見切れ防止
- music_bedのループ区間は**VO(ナレーション)が乗っていない楽曲のみの区間**を使うこと

## 5. カバー画像(1080x1920 JPG)

- 笑顔+カメラ目線のフレームを選ぶ(顔優先)。テキストは顔の下に配置
- 構成: 下部グラデーション(黒)+ 白太字メッセージ(強調1〜2ワードを黄色 `(255,214,64)`)+ 赤バッジ `(214,40,57)`(サブ情報)
- IGグリッド1:1クロップ安全域(y420〜1500)内にテキストを収める
- 2〜3案作って比較で見せる

## 6. 納品フォーマット

1. 動画mp4(1080x1920/30fps/H.264/yuv420p/faststart、最終 `-preset medium -crf 18`)
2. カバーJPG(採用案)
3. IGキャプション: ①1行目フック ②引用ブロック ③本人の一言(founder文脈)④質問CTA👇 ⑤🇯🇵日本語補足3文 ⑥ハッシュタグ7個
4. 固定コメント(3行以内)
5. チェックリスト: 位置情報 / 音源の載せ方(ビート合わせ地点=フラッシュ明け秒数を明記)/ 推奨投稿時刻 17:00 PT

## 7. ブランド文脈(キャプション執筆用)

- Kodai = SILK THE RICH 共同創業者(LA在住、US市場向け発信、founderブランディング最優先)
- 富岡製糸場を運営していた**片倉(片倉財閥/片倉興産)は現在SILK THE RICHの株主**。ブランドは「世界遺産を背負う正統継承シルクブランド」という文脈が使える
- 強ワード: 数字(80%、115年、15,000→200)、JAPAN、heritage、UNESCO
- 英語コピーは短文の言い切り+対句("Not as a trend — as an inheritance.")
