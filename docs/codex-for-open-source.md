# Codex for Open Source: fact-check

Checked: 2026-08-09

## Conclusion

OpenAI's Codex for Open Source program is real, but the claim that anyone can
receive "$1,200" by creating a public GitHub repository goes beyond what the
official program information guarantees.

## Confirmed by OpenAI

- Open-source maintainers can apply.
- Selected participants can receive six months of ChatGPT Pro with Codex.
- The program also mentions API credits and Codex Security.
- The program is intended to support maintainers of important open-source
  software.

## Not confirmed

The official information reviewed does not say that:

- any public repository makes its owner eligible;
- a new or unfinished project will be accepted;
- GitHub Stars determine acceptance;
- installing Cursor, Claude Code, or another coding tool is required;
- every applicant receives a fixed $1,200 API credit.

## Why "$1,200" appears in social posts

The number is commonly presented as a valuation of six months of ChatGPT Pro.
It should not be described as cash or as a guaranteed $1,200 API balance. OpenAI
describes the benefits separately as ChatGPT Pro access and API credits.

## Practical takeaway

Apply when you can demonstrate ongoing maintenance and real-world use of an
open-source project. A repository created only for the application, or Stars
collected from friends, is not evidence of meaningful adoption.
